# Contributing to Allium

Thanks for helping improve Allium.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your change with a clear, small commit.
4. Test it with Python 3.8 or newer.
5. Open a pull request with a short description of what changed and why.

## Guidelines

- Keep it stdlib-only. No new third-party dependencies.
- Do not add guessed onion URLs. Only add sources you have verified live.
- Do not include personal data, credentials, or real case data in issues or pull requests.
- Keep the menu-driven, no-typing interface simple.

## Reporting issues

Open an issue with what you tried, what you expected, and what happened instead.
